ℹ️ About

This DApp demonstrates a complete post-quantum-ready smart account system on Arc Testnet, following Circle's PQ security roadmap. It features pluggable signature modules (ECDSA, hash-based, hybrid), 7-day timelocked migration, M-of-N social recovery, and an optional stealth-address privacy layer (ERC-5564 inspired). All contracts are verified on Blockscout. Built with Solidity + Foundry, frontend in vanilla HTML + ethers.js. Fully open source.
